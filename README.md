One code review comment that approves a pull request while carrying quiet existential dread. The entry is the winner of a 14-candidate blind pairwise tournament, calibrated 4–0 against previous genre winners: "LGTM. Merging before the flaky test changes its mind. It knows what it did."

## Run it

```sh
python3 main.py
```

Writes the single-line entry (75 characters, no trailing newline) to `/output/entry.txt`.
